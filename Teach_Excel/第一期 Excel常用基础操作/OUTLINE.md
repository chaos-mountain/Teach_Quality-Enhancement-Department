## 第一部分（13 min）：认识界面 + 做一张基础表格

### 1.1 认识 Excel 界面（3 min）

**只讲用得着的，不讲全：**

| 界面区域 | 作用 | 一句话说明 |
|----------|------|-----------|
| 功能区（菜单栏） | 所有操作的入口 | **"开始"选项卡最重要**，字体/对齐/数字格式全在里面 |
| 名称框 + 编辑栏 | 看内容、改内容、写公式 | 选中单元格后这里显示里面的真实内容 |
| 表格区 | 主要工作区 | 由单元格构成，用 **列字母 + 行数字** 定位（如 A1、B3） |
| 工作表标签 | 切换不同的 Sheet | 一个文件可以有多个工作表，可改名、换颜色 |
| 状态栏 | 实时快捷信息 | 选中数字自动显示求和/平均值/计数（超实用！） |

**不讲**：插入、页面布局、公式、数据等选项卡——后面用到再说

### 1.2 五分钟做出一张表（5 min）

**操作演示，同学跟着做：**

1. 打开 Excel → 看到一片空白格子
2. A1 输入"序号"→ **Tab** 移到 B1 → 依次输入 8 个列标题
3. 输入 3~5 行示范数据（姓名、车型、预算等）
4. 选中标题行 → **加粗** + **填充底色** + **加边框**
5. 双击列标之间的线（或拖拽表格线）→ 自动适配列宽
6. 需要新增数据 → 右键插入行/列 → 写标题、填数据
7. ⚠️ **常见翻车现场**：打印预览发现表格线消失了！→ 原因：Excel 灰色网格线只是参考线，不会打印 → **必须手动加边框**

**一张能用的表格就做好了！✅**

### 1.3 自动填充——省力神器（2 min）

- 输入"1" → 按住右下角**小黑点（填充柄）**往下拖 → 1, 2, 3…
- **双击填充柄** → 旁边有数据时自动填满整列
- 序列也能自动识别：星期一→星期二… / 1月→2月… / 第1组→第2组…
- ⚠️ 注意：如果旁边列有空行，双击填充会在空行处停止

### 1.4 数据的移动与转换（2 min）

**移动数据：**
- 拖拽单元格边框 → 移动到新位置
- 按住 **Ctrl** 拖拽 → 复制到新位置
- 按住 **Shift** 拖拽 → 插入到两行/两列之间

**行与列的转置（调换方向）：**
- 场景：行标题想变成列标题，或反过来
- 操作：复制数据区域 → 右键 → 选择性粘贴 → 勾选"转置"→ 确定
- 举例：横排的 8 个列标题，一键变成竖排

### 1.5 单元格内换行（0.5 min）

- 普通回车 → 跳到下一个单元格
- **Alt + Enter** → 在当前单元格内换行
- 场景：一个单元格里写两行内容，如"车型：小米 SU7\n排量：1.5L"

### 1.6 绘制表格对角线（0.5 min）

> 表头左上角常常需要斜线分隔"行标题"和"列标题"

**方法一（快捷）：**
- 开始 → 字体 → 边框下拉 → 绘制边框 → 手动对角线一笔画完

**方法二（精确）：**
- 右键单元格 → 设置单元格格式 → 边框 → 选择对角线样式 → 确定

## 第二部分（16 min）：单元格格式 + 表格美化 + 冻结/排序/筛选

---

### 2.1 ✨ 单元格数据类型与格式（5 min）

> 这是本节最重要的基础概念！单元格里的数据是有"身份"的——类型不对，计算就出错。

#### 2.1.1 为什么要区分数据类型

| 常见翻车现场 | 原因 | 解决 |
|-------------|------|------|
| 数字求和结果是 0 | 数字被存成了"文本" | 转成"数值" |
| 日期无法排序 | 日期格式不统一 | 统一设成"日期" |
| 金额只显示数字没有 ¥ 符号 | 没设货币格式 | 设成"货币" |
| 输入 1/2 变成 1月2日 | Excel 把它理解成日期了 | 设成"分数"或前面加引号 |

**一句话总结：数据不仅要输对，还要让 Excel "认识"它的类型。**

#### 2.1.2 常用数据类型一览

| 数据类型 | 长什么样 | 什么时候用 | 本例对应 |
|----------|---------|-----------|----------|
| **文本** | 左对齐，绿色小三角标记（如被误识别） | 姓名、地址、编号 | 姓名、车型、家乡 |
| **数值** | 右对齐，可设小数位数 | 数量、长度、可计算的数字 | 排量(L) |
| **货币** | ¥ 前缀 + 千分位分隔符 | 金额、预算、价格 | 购车预算 |
| **日期** | yyyy/mm/dd 或 年月日 | 日期、生日、截止日 | （可选新增列）购车日期 |
| **百分比** | 数字 + % | 占比、增长率 | 驾照率（=11/20 → 55%） |
| **分数** | 真分数格式 | 几分之几 | 1/2（不会被误认为日期） |

#### 2.1.3 如何设置数据类型

**方法一（最快）：**
- 开始 → 数字格式下拉框 → 选"货币"/"百分比"/"日期"等

**方法二（最全）：**
- 选中单元格 → **Ctrl + 1** → 数字选项卡 → 左边选类别 → 右边调细节
  - 数值：设小数位数、是否用千分位
  - 货币：选符号（¥ / $）、设小数位数
  - 日期：选显示格式（2026/6/28 / 二〇二六年六月二十八日 / 6-28）
  - 百分比：自动 ×100 并加 % 号

#### 2.1.4 实操练习：给车辆数据表设格式

> 用 Ctrl+1 打开设置窗口，逐一设置各列：

| 列 | 设置类型 | 效果 |
|----|---------|------|
| 排量(L) | 数值 → 1位小数 | 1.5 / 2.0 / 0.8 |
| 购车预算 | 货币 → ¥ → 0位小数 | ¥180,000 / ¥120,000 / ¥220,000 |
| 是否有驾照 | 文本（默认即可） | 是 / 否 |

#### 2.1.5 文本 vs 数字的快速识别方法

- **选中数字列** → 看状态栏 → 有求和 = 数字 / 无求和 = 文本（被坑了！）
- **文本转数字**：选中 → 点黄色警告图标 → 转换为数字
- **输入长数字（如学号、手机号）**：先输入单引号 `'` 再输入数字 → 不会丢位

- **"同一数据不同格式"对比**：同一个数字，分别设成数值/货币/文本/日期，展示不同外观

### 2.3 冻结窗格——滚动不迷路（3 min）

> 现场演示效果最好的功能之一

- **痛点**：50 行数据往下滚，表头不见了，不知道每列是啥
- **冻结首行**：视图 → 冻结窗格 → 冻结首行
- **冻结多行/列**：选中某个单元格 → 冻结窗格 → 冻结该格上方 + 左侧所有行列
  - 例：选中 B2 → 冻结 → 第 1 行和 A 列都不会滚走

### 2.4 排序与筛选（3.5 min）

**排序——将数据按一定规则排列：**
- 选中数据区域 → 开始 → 排序和筛选 → 自定义排序
- 练习①：按"购车预算"从低到高排
- 练习②：先按"是否有驾照"排，再按"预算"从高到低排（多级排序）
- ⚠️ 排序前确保所有列都被选中，否则只有一列变了其他列不动！

**筛选——只看我们指定的数据：**
- 选中标题行 → 开始 → 排序和筛选 → 筛选 → 点下拉箭头筛选
- 练习①：只看"有驾照"的同学
- 练习②：数字筛选 → 介于 → 只看预算 ¥150,000~¥250,000 之间的车
- 练习③：文本筛选 → 包含"比亚迪"→ 只看比亚迪车型
- 清除筛选：点筛选按钮 → 从"xxx"清除筛选

### 2.5 行列操作速讲（1.5 min）

- 双击列边界 = 自动适配列宽
- 右键 → 插入/删除 行或列
- 拖拽列边界手动调整宽度
- 多列同时设宽：选中多列 → 拖拽任意一列边界 → 所有选中的列统一宽度

## 第三部分（12 min）：基础函数（5个）

> 🚗 用车辆数据出题，贴近汽车学院

### 3.1 公式基础——一切从 = 开始（2 min）

- `= 1 + 1` → 回车得到 2
- `= G2 * 10` → 排量 × 10
- 加减乘除：`+ - * /`
- 运算优先级：乘除优先于加减，用括号 `()` 改变顺序
- 单元格引用做计算：`=H2+H3` → 张明轩和钱一鸣的预算之和

### 3.2 统计四件套：SUM / AVERAGE / MAX / MIN（5 min）

> 场景：快速了解全班车辆数据概况

| 函数 | 用途 | 示例 | 结果说明 |
|------|------|------|----------|
| `=SUM()` | 求和 | `=SUM(H2:H21)` | 全班购车预算总和 |
| `=AVERAGE()` | 平均值 | `=AVERAGE(G2:G21)` | 平均排量 |
| `=MAX()` | 最大值 | `=MAX(H2:H21)` | 最高预算是谁 |
| `=MIN()` | 最小值 | `=MIN(H2:H21)` | 最低预算是谁 |

- **状态栏秒看**：选中数字区域，右下角自动显示平均值+计数+求和
- **Alt + =**：一键自动求和——光标放数据下方，按快捷键直接出结果
- ⚠️ 如果 SUM 结果为 0 → 检查数据是不是被存成了文本（回到 2.1！）

### 3.3 IF() 条件判断（5 min）

> 场景：根据是否有驾驶照亮"红绿灯"

**基础语法：**
```
=IF(条件, 成立时返回什么, 不成立时返回什么)
```

**三个实战例子（难度递增）：**

① 文字判断：
- `=IF(D2="是", "✅ 可上路", "❌ 需考证")`
- 如果 D2（是否有驾照）是"是"，显示"可上路"；否则显示"需考证"

② 数字判断：
- `=IF(H2>200000, "高预算", "普通预算")`
- 如果 H2（购车预算）> ¥200,000，标记"高预算"

③ 嵌套判断（IF 里再套 IF）：
- `=IF(H2>250000, "豪车党", IF(H2>150000, "中产党", "代步党"))`
- 像剥洋葱：先判断 >250000 → 再判断 >150000 → 剩下的归一类

**本节只讲这 5 个：SUM、AVERAGE、MAX、MIN、IF**（多了记不住，但这 5 个能解决 80% 的场景）

### HTML 设计
- **实时公式演示器**：上方 20 行数据表，下方输入框写公式，实时出计算结果
- **数据区域高亮动画**：鼠标悬停函数名时，对应的数据列自动高亮闪烁
- **IF 函数决策树图**：像分叉路口 → 条件成立走左边 / 不成立走右边，视觉化展示

## 第四部分 ✨（8 min）：超级表——让普通表格进化

> 前面手动加了边框、填了底色、写了公式……其实这些都可以一键搞定！
> 这就是超级表——**本节第一个"哇塞"时刻**。

### 4.1 什么是超级表（1.5 min）

- 普通区域 vs 超级表 → **按下 Ctrl+T 的瞬间变化**
- 自动获得：斑马纹配色 + 筛选按钮 + 边框
- 核心优势：新增数据 → 格式、公式、下拉列表**自动延伸**（不用手动拖！）
- 回顾：之前第二部分手动做的那些美化，超级表一键就完成了

### 4.2 一键创建超级表（2 min）

1. 光标放在数据区域内任意位置
2. 按下 **Ctrl + T**（或：开始 → 套用表格格式）
3. 确认"表包含标题"→ 确定
4. 瞬间美化！样式还能在"表格设计"选项卡里换颜色方案
5. ⚠️ 如果数据区域有空行空列，需要手动框选完整范围

### 4.3 超级表的实用特性（3.5 min）

- **自动扩展**：在下方输入新行（快捷键Tab） → 格式自动跟上，公式自动复制，不用手动拖
- **标题行冻结**：往下滚动，标题自动顶到列标位置（天然冻结！回顾 2.3 手动冻结的步骤，超级表自动就搞定了）
- **汇总行**：表格设计 → 勾选"汇总行"→ 底部自动出现统计行（可下拉选 SUM/AVERAGE/COUNT 等）
- **结构化引用**：写公式用 `[@列名]` 代替 `A1`，更直观（如 `=[@购车预算]*0.1`）
- **切片器（将杂乱的数据进行类目整理）**（预告）：下一节做看板的核心武器！

### 4.4 超级表 vs 普通区域 最终对比（1 min）

| 特性 | 普通区域（手动模式） | 超级表（一键模式） |
|------|---------------------|-------------------|
| 美化 | 手动加边框底色 | 一键完成，多种配色可选 |
| 新增数据 | 格式不会自动跟，需手动拖 | 自动扩展，格式+公式全跟上 |
| 滚动时标题 | 滚远了就看不见（需手动冻结） | 自动顶到列标位置 |
| 写公式 | 用 A1、B2 地址 | 用 [@列名] 引用（更直观） |
| 汇总行 | 需手动用 SUM 函数 | 一键勾选，自动生成 |

### HTML 设计
- **"手动模式 vs 超级表"对比切换**：点击按钮，同一份数据在两种形态间切换
- **自动扩展动效**：在超级表下方新增一行，高亮展示格式自动跟随
- **汇总行动态演示**：勾选汇总行后，底部统计行出现的动画

## 第五部分 ✨（12 min）：可视化看板——一切串起来！

> 全场最大的"哇塞"时刻！用前面学的所有技能 + 超级表，做一个实时互动看板。

### 5.1 什么是可视化看板（1 min）

- 看板 = 汇总指标 + 图表 + 可筛选，**一个屏幕看完所有关键信息**
- 类比：汽车仪表盘 → 速度、油量、转速、水温尽收眼底
- Excel 看板 → 总人数、平均预算、驾照率、图表…全在一屏

### 5.2 看板三大组件（2 min）

```
┌──────────────────────────────────────────────────┐
│  📊 汽车工程学院新生车辆信息看板                    │
├──────────┬──────────┬──────────┬─────────────────┤
│ 👥 总人数 │ 💰 平均预算 │ 🪪 驾照率  │ 🚗 最热车型     │  ← 汇总卡片
│   20人   │ ¥195,500 │   55%    │   小米SU7      │     (SUM/AVERAGE/IF)
├──────────┴──────────┼──────────┴─────────────────┤
│ 预算分布柱状图       │  驾照比例饼图                 │  ← 图表
│ ██████████████      │  ◔◔◔◔◔◔◔◔◔◔             │
├─────────────────────┼────────────────────────────┤
│ 家乡       │ 驾照    │  详细数据表（超级表）          │  ← 切片器 + 超级表
│ [上海][杭州]│ [是][否]│  （点击切片器筛选）            │
└─────────────────────┴────────────────────────────┘
```

### 5.3 在 Excel 里搭建看板的步骤（7 min）

> 一步步实操演示

**Step 1：准备超级表（1 min）**
- 把数据区域转成超级表（Ctrl+T）—— 就是上一节刚学的内容！

**Step 2：创建汇总卡片区（2 min）**
- 在看板顶部用函数计算 4 个关键指标：

| 指标 | 公式 | 显示效果 |
|------|------|----------|
| 总人数 | `=COUNTA(表[姓名])` | 20 人 |
| 平均预算 | `=AVERAGE(表[购车预算])` | ¥195,500 |
| 驾照率 | `=COUNTIF(表[是否有驾照],"是") / COUNTA(表[姓名])` | 55%（设百分比格式） |
| 最热车型 | 筛选后目测即可 | 小米 SU7 |

- 💡 把汇总卡片字号调大、加底色、加边框 → 像仪表盘上的数字一样醒目
- 💡 超级表的结构化引用（`表[列名]`）比 A1 地址好理解多了！

**Step 3：插入图表（2 min）**
- **柱形图**：选中"姓名"和"购车预算"两列 → 插入 → 簇状柱形图 → 每人预算一目了然
  - 可设数据标签显示具体金额
- **饼图**：用驾照数据做辅助统计表 → 插入饼图 → 有驾照 vs 无驾照比例
  - 辅助表：两行两列（有驾照 11 人 / 无驾照 9 人）→ 选中 → 插入饼图

**Step 4：插入切片器——全场最佳效果！（2 min）**
- 光标放在超级表内 → 表格设计 → 插入切片器
- 勾选"是否有驾照"和"家乡"→ 得到两个筛选按钮组
- **点切片器，数据表 + 图表全部同步变化！** ← 同学看了会"哇"

### 5.4 切片器联动演示——现场互动（2 min）

> 让同学喊筛选条件，主讲人点切片器，大家看变化

- "只看有驾照的同学"→ 点"是"→ 表格从 20 人缩到 11 人，柱形图和饼图同步更新
- "只看上海的同学"→ 再点"上海"→ 聚焦上海同学的数据
- "没驾照且预算低于 ¥150,000"→ 组合筛选 → 数据瞬间筛选出来
- "全部清除"→ 点切片器右上角的清除按钮 → 一键恢复全貌

### HTML 设计（核心亮点！）
- **完整看板模拟页面**：
  - 顶部 4 个汇总指标卡片（大字号 + 图标 + 彩色背景）
  - 左侧柱形图 + 右侧饼图（Chart.js 渲染，带动画）
  - 底部超级表数据清单
  - **切片器按钮**：点击"是/否"或家乡名称 → 表格 + 图表同步联动筛选
- 这个环节是全场互动性最强的部分，也是 Excel 能力的最直观展示
