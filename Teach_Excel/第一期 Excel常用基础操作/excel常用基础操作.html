Excel 简介——功能与适用范围

Excel 是 Microsoft Office 套件中的电子表格软件，核心功能涵盖数据录入、统计计算、图表可视化、报表制作等。 广泛应用于财务管理、实验数据处理、进销存管理、学术论文分析、工程预算等场景。 无论是汽车工程实验数据整理、毕业论文数据分析，还是职场中的日报周报、KPI 看板，Excel 都能高效胜任。 掌握 Excel 基础操作，是工科学生和职场人士的必备技能。

适用人群：零基础初学者、想系统梳理 Excel 技能的在校学生及职场新人。

1.1 认识 Excel 界面（3 min）

界面区域作用一句话说明

1.2 五分钟做出一张表（5 min）

  1. 打开 Excel → 看到一片空白格子
  2. A1 输入"序号" → Tab 移到 B1 → 依次输入 8 个列标题
  3. 输入 3~5 行示范数据
  4. 选中标题行 → 加粗 + 填充底色 + 加边框
  5. 双击列标之间的线 → 自动适配列宽
  6. 需要新增数据 → 右键插入行/列
常见翻车现场：打印预览发现表格线消失了！→ Excel 灰色网格线只是参考线不会打印，必须手动加边框。

一张能用的表格就做好了！✅

1.3 自动填充——省力神器（2 min）

  • 序列也能自动识别：星期一→星期二… / 1月→2月… / 第1组→第2组…

👇 点击"填充"按钮看效果

数据不仅有"值"，还有"身份"——类型不对，计算就出错！

常见翻车现场原因解决
数字求和结果是 0数字被存成了"文本"转成"数值"
日期无法排序日期格式不统一统一设成"日期"
金额没有 ¥ 符号没设货币格式设成"货币"
输入 1/2 变成 1月2日Excel 理解成日期了设成"分数"或开头加 '
试试看：同一个数 → → 显示为： 180000

原始值 180000，切换格式看外观变化

类型长什么样什么时候用本例对应

3.1 公式基础——一切从 = 开始（2 min）

= 1 + 1 → 回车得到 2

加减乘除：+ - * / | 括号 () 改变运算顺序

单元格引用：=H2+H3 → 张明轩和钱一鸣的预算之和

3.2 统计四件套：SUM / AVERAGE / MAX / MIN（5 min）

函数用途汽车学院例子结果
=SUM()求和=SUM(H2:H21)-
=AVERAGE()平均值=AVERAGE(G2:G21)-
=MAX()最大值=MAX(H2:H21)-
=MIN()最小值=MIN(H2:H21)-
选中数字区域，看右下角状态栏——求和/平均值/计数自动显示！
Alt + =：一键自动求和，光标放数据下方直接按！

🧪 公式实时演示器

下方是 20 条数据，输入公式查看结果（例：=SUM(H2:H21) / =AVERAGE(G2:G21) / =MAX(H2:H21) / =IF(D2="是","可上路","需考证")）

3.3 IF() 条件判断（5 min）

条件
D2="是" ?
→ 是 →
✅ 可上路
→ 否 →
❌ 需考证

=IF(D2="是", "✅ 可上路", "❌ 需考证")

难度例子说明
基础=IF(D2="是","可上路","需考证")文字判断
进阶=IF(H2>200000,"高预算","普通预算")数字判断
嵌套=IF(H2>250000,"豪车党",IF(H2>150000,"中产党","代步党"))洋葱式判断

本节只讲这 5 个：SUM、AVERAGE、MAX、MIN、IF——能解决 80% 的场景！

📋 函数速查卡

函数语法一句话
SUM=SUM(范围)全部加起来
AVERAGE=AVERAGE(范围)求平均数
MAX=MAX(范围)找最大的
MIN=MIN(范围)找最小的
IF=IF(条件,成立返回,不成立返回)如果…就…否则…

超级表——让普通表格进化

8 min
前面手动加了边框、填了底色、写了公式……其实这些都可以一键搞定！这就是超级表。

4.1 什么是超级表（1.5 min）

选中数据区域 → 按下 Ctrl + T → 瞬间获得：

✅ 斑马纹配色 ✅ 筛选按钮 ✅ 边框 ✅ 自动扩展 ✅ 标题自动冻结

4.2 一键创建超级表（2 min）

  1. 光标放在数据区域内任意位置
  2. 按下 Ctrl + T
  3. 确认"表包含标题"→ 确定
  4. 瞬间美化！样式还能在"表格设计"选项卡里换

4.3 超级表的实用特性（3.5 min）

  • 自动扩展：下方输入新行 → 格式 + 公式自动跟上
  • 标题行固定：往下滚动，标题自动顶到列标（天然冻结！）
  • 汇总行：表格设计 → 勾选"汇总行" → 自动统计
  • 结构化引用：写公式用 [@列名] 代替 A1，更直观

4.4 手动模式 vs 超级表（一键模式）

特性手动模式超级表（一键模式）
美化手动加边框底色一键完成 ✅
新增数据格式不自动跟自动扩展 ✅
标题滚动滚远看不见自动顶到列标 ✅
写公式A1、B2 地址[@列名] 引用 ✅
汇总行手动 SUM一键勾选 ✅
